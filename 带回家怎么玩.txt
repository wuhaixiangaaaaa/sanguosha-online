==============================================================
  三国杀 · 在家开联机（朋友在外地）操作指南
==============================================================

把《三国杀联机版》整个文件夹拷回家（U 盘 / 网盘 / 微信文件传输
均可），不需要拷公司电脑里的任何其他东西。


【第一步】安装 cpolar（只装这一次）
--------------------------------------------------------------
方法 A（推荐）：直接双击本文件夹里的 cpolar_amd64.msi，
                一路"下一步"装完即可。（Intel / AMD 电脑都能用）

方法 B（安装包损坏时备用）：去官网重新下载
   1. 浏览器打开  https://www.cpolar.com
   2. 右上角登录你的账号（whxwhx123）
   3. 左侧菜单「下载」→ 选 Windows 版本下载安装


【第二步】配置令牌（只配这一次）
--------------------------------------------------------------
1. 按 Win+R，输入 cmd，回车，打开黑色命令窗口
2. 把下面这一整行复制进去，回车：

   cpolar authtoken MDY4MGE4ODAtZTQ3MC00MTBlLWI0NTYtMzNmN2ViOWEwNzQ3

3. 看到 Authtoken saved ... 字样就成功了。

（令牌如果以后找不到：登录 https://www.cpolar.com
  → 左侧「验证」页面可随时再查看复制）


【第三步】以后每次开玩
--------------------------------------------------------------
1. 双击《启动联机外网.bat》
2. 等十几秒，公网网址会自动复制到剪贴板
   （也会存一份到桌面的 sgs-url.txt）
3. 微信里 Ctrl+V 粘贴发给朋友
4. 你自己：浏览器打开 http://localhost:8080
   → 联机对战 → 创建房间，把房间号告诉朋友
5. 朋友：打开你发的网址 → 联机对战 → 输昵称和房间号

玩完把任务栏上多出来的几个窗口（SGS-Server、cpolar-tunnel）
关掉即可。


==============================================================
  其他玩法（顺便）
==============================================================

· 自己在家单机玩：直接双击 index.html，什么都不用装。
· 朋友来你家连同一个 WiFi：双击《开始游戏.bat》，朋友浏览器
  打开窗口里显示的 http://192.168.x.x:8080。


==============================================================
  常见问题
==============================================================

· 双击 bat 提示 cpolar is not installed
  → 先做【第一步】【第二步】。

· 朋友打不开网址 / 网址进不去游戏
  → 确认任务栏的 SGS-Server 窗口还开着；
  → 确认公司那台电脑的 cpolar 已关闭（免费版同时只能一条
    隧道在线，两边同时开会互相抢）。

· 朋友听不到音效
  → 让他进入页面后先随便点一下屏幕（浏览器要求点过才允许
    出声），还不行就点屏幕顶部的「开启音效」按钮。

· 界面内容看起来是旧的
  → 双方浏览器都按 Ctrl+F5 强制刷新一次。

· runtime 文件夹是游戏服务器运行环境，不要删。
